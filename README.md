# 🏦 Banking Loan Portfolio Analysis | SQL & Power BI

## 📌 Project Overview

The **Banking Loan Portfolio Analysis** project is an end-to-end data analytics project designed to analyze banking loan data, evaluate portfolio performance, understand credit risk, and generate meaningful business insights.

Using **MySQL** for data cleaning and SQL-based analysis and **Power BI** for interactive visualization, this project transforms raw banking data into actionable information to support data-driven decision-making.

The project focuses on three major analytical areas:

1. Loan Portfolio Overview
2. Credit Risk & Loan Performance
3. Customer & Borrower Analysis

## 🎯 Project Objectives

- Analyze the overall loan portfolio and lending performance.
- Evaluate approved, rejected, and defaulted loans.
- Monitor outstanding and repaid loan amounts.
- Understand credit risk and repayment performance.
- Analyze customer financial profiles and credit scores.
- Compare loan distribution across different regions.
- Explore the relationship between employment type and loan amounts.
- Build an interactive Power BI dashboard for business analysis.

### 1. Data Understanding
